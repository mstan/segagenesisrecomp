# E18: same-drain independent FM shadow synthesis

The retained engine change overlaps the already opted-in FM shadow with canonical FM/PSG synthesis. Common ordering, register pairing and deferred events remain owner-controlled. A persistent SDL worker consumes the immutable FM event interval; the owner joins it before shadow verification/substitution, diagnostics, return or snapshot boundaries. The shadow feature remains disabled by default. When it is enabled, a worker is selected once after initialization. Diagnostic GENESIS_ENGINE_WORKERS=off/0, compile-disabled workers, hosts reporting fewer than two logical CPUs through SDL, creation failure and aliased output arrays retain serial execution. No extra frame, guest-state representation, title adapter or graphics change is introduced.

The selected E18 opportunity was evaluated across three independently schedulable architectures. Immutable final-color preparation overlapped with audio did not repay its dispatch/copy costs. Independent FM/PSG jobs repeatedly worsened RKA runtime/cycles and were rejected. Independent shadow synthesis showed useful RKA wall-time observations and was retained after reassessment. Rejected rendering/chips code and simulation hooks were removed, rather than left as unused infrastructure. A below-chip FM algorithm rewrite belongs to E20; future resident GPU jobs belong to E37.

# Genesis recompiler v0.1.1

Fixes found during the Sonic 1–3 coverage and widescreen pass:

- Preserve the full bus address when checking a game's periodic PLC work.
  A WRAM counter must not alias ROM at the same low 16-bit offset.
- Extract jump tables whose first entry follows a local label on the same
  source line. Rebuild Sonic 1 discovery from the byte-identical REV00
  assembly listing, including nested includes and bare RTS targets.
- Pin the shared 68000 generator correction for mixed-width stack data.
  Two word pushes followed by one long pop no longer cause a false early
  return. This fixes the reproduced IceCap column stack failure.
- Let input-bridge tests honor the pinned launcher's supported bind pages
  while retaining the engine's four-device assignment tests.

Validation: 12 generated-C stack cases pass with GCC on both qualified
Genesis profile revisions; MSVC builds pass 72 consumer CTests. Sonic 1/2
pass 78 exact RAM, VRAM and screenshot route replays. Sonic 1 gains 156
native instruction starts without losing any. Eighteen affected Sonic 1
routes match retained interpreter-floor references exactly. Sonic 3's
32 level-select routes and 13 attract routes pass strict stack checking
at 32:9. These are bounded assisted coverage checks, not complete victories
or cross-build netplay qualification.

No ROMs are distributed. Runtime and generator changes use portable C.

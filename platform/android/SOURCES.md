# Android component sources

The game-specific source, configuration and pinned shared components are in
the corresponding game repository. Sonic 3 & Knuckles uses
https://github.com/mstan/Sonic3AndKnucklesRecomp. Clone with submodules to obtain
the pinned source revisions.

Shared framework: https://github.com/mstan/segagenesisrecomp

Launcher: https://github.com/mstan/recomp-ui

SDL 2: https://github.com/libsdl-org/SDL/tree/release-2.32.10

The framework's `THIRD-PARTY-LICENSES.md` identifies the included runtime
components. Their license texts, the game/framework/launcher licenses and the
full font licenses are included beside this file. The launcher font and image
NOTICE files describe their respective assets. No game cartridge is included.
